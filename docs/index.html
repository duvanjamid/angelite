Inicio rápido

Un solo <script>. Todo lo que ves en esta página se ejecuta con el código que aparece debajo de cada demo.

<div id="app"></div>
<script src="angelite-lite.min.js"></script>
<script>
  const { signal, component, mount } = AngeLite;

  class App {
    count = signal(0);
    inc() { this.count.update(n => n + 1); }
  }

  component(App, {
    template: `<button (click)="inc()">Clicks: {{ count() }}</button>`
  });

  mount(App, document.getElementById('app'));
</script>

Con npm: npm i @duvanjamid/angelite y import { signal, component, mount } from '@duvanjamid/angelite/lite'.

Señales

El estado vive en signal(). Al leer una señal dentro de una plantilla, esa parte concreta del DOM se suscribe sola: cuando la señal cambia, solo se actualiza ese nodo de texto, atributo o bloque. No hay árbol virtual ni ciclo de detección de cambios.

  • signal(v) – valor escribible: s(), s.set(x), s.update(fn)
  • computed(fn) – derivada, perezosa y cacheada
  • effect(fn) – efecto secundario; devuelve una función para detenerlo

Las actualizaciones se agrupan en un microtask: varios set() seguidos provocan un único repintado.

Plantillas

SintaxisQué hace
{{ expr }}Interpolación. Siempre texto: nunca se interpreta como HTML.
[prop]="expr"Enlaza una propiedad del DOM (o un input() de un componente hijo).
[class.x] · [style.width.px] · [attr.x]Clases, estilos (en kebab-case) y atributos.
(evento)="expr"Escucha eventos; $event disponible. Varias sentencias con ;.
[(ngModel)]="sig"Enlace bidireccional con una señal escribible.
{{ x | pipe:arg }}Pipes encadenables.

Las expresiones las ejecuta un intérprete propio (sin eval): soporta operadores, ternario, ?., ??, índices y llamadas a métodos.

Control de flujo

La misma sintaxis de bloques que Angular 17+. @for reutiliza los nodos del DOM según track, así que reordenar no recrea elementos.

Variables disponibles dentro de @for: $index, $count, $first, $last, $even, $odd.

Formularios

Componentes

Un componente es una clase + component(Clase, { selector, template, imports }). Los inputs son input() (una señal escribible), los outputs son output(), y <ng-content> proyecta el contenido. Los hooks ngOnInit y ngOnDestroy funcionan como en Angular.

En HTML las etiquetas personalizadas no se pueden auto-cerrar: escribe siempre <ui-card></ui-card>.

Router

Router por hash, mínimo pero funcional: parámetros (:id), comodín **, <router-outlet> y routerLink. (No lo activo en esta página para no pisar sus anclas.)

const { component, mount, provideRouter, router } = AngeLite;

class Home {}
component(Home, { template: `<h2>Inicio</h2>` });

class User { id = () => router.params().id; }
component(User, { template: `<h2>Usuario {{ id() }}</h2>` });

class NotFound {}
component(NotFound, { template: `<h2>404</h2>` });

provideRouter([
  { path: '/',          component: Home },
  { path: 'users/:id',  component: User },
  { path: '**',         component: NotFound }
]);

class App {}
component(App, {
  template: `
    <nav><a routerLink="/">Inicio</a> <a routerLink="/users/42">Usuario 42</a></nav>
    <router-outlet></router-outlet>`
});
mount(App, document.getElementById('app'));

Precompilar plantillas (opcional)

Por defecto Lite compila las plantillas en el navegador: un solo script, sin build. Si te importa cada KB, puedes convertir las plantillas en JS durante el build y enviar solo el runtime (sin parser de expresiones ni compilador): unos ~5 KB gzip en total para una app real, menos que Preact.

// counter.ng.html
<button (click)="inc()">Clicks: {{ count() }}</button>

// counter.js
import { signal, component, mount } from '@duvanjamid/angelite/lite/runtime';
import aot from './counter.ng.html';              // compilada por el plugin

class Counter { count = signal(0); inc() { this.count.update(n => n + 1); } }
component(Counter, { aot });                       // en lugar de template
mount(Counter, document.body);

// build (esbuild)
import { aotPlugin } from '@duvanjamid/angelite/tools/aot.mjs';
esbuild.build({ entryPoints: ['counter.js'], bundle: true, minify: true, plugins: [aotPlugin({ components: ['ui-button'] })] });

También hay una CLI: node tools/aot.mjs plantilla.html salida.js --components ui-button,ui-card. El código generado se comprueba en los tests: una plantilla precompilada produce exactamente el mismo DOM que la compilada en el navegador. Los pipes integrados son opt-in en este modo: import '@duvanjamid/angelite/lite/pipes' o registra los tuyos con registerPipe.

La herramienta usa jsdom solo en tiempo de build. En producción no se carga nada de ella.

Seguridad

El modelo es simple: las plantillas son código tuyo; los datos que muestras no son de fiar. Lite está hecho para que un dato no se convierta en HTML, script o URL peligrosa por accidente.

  • {{ valor }} siempre se inserta como texto.
  • Las URL en href, src, action… solo dejan pasar http(s), mailto, tel, sms, ftp y rutas relativas; lo demás pasa a unsafe:… y avisa en consola.
  • [innerHTML] solo pinta HTML envuelto en trustHtml(); cualquier otro valor se inserta como texto.
  • [onclick], [srcdoc] y bindings sobre <script>/<base>/<link> son un error de compilación.
  • Las expresiones nunca reciben window ni document, vengan de donde vengan.
  • Sin eval ni new Function: funciona con una CSP sin unsafe-eval, y soporta Trusted Types.
import { signal, trustHtml, trustUrl } from '@duvanjamid/angelite/lite';

html = signal(trustHtml(DOMPurify.sanitize(comentario)));   // tú te haces responsable: sanea antes
link = signal(trustUrl('whatsapp://send?text=hola'));       // esquema propio permitido a propósito

// CSP recomendada
// Content-Security-Policy: default-src 'self'; script-src 'self'; require-trusted-types-for 'script'; trusted-types angelite

El sandbox de expresiones es defensa en profundidad, no un límite de seguridad: nunca compiles plantillas que incluyan datos de usuario. En producción precompila con tools/aot.mjs. Más detalle en SECURITY.md.

Diferencias con Angular

Es "homólogo", no un clon. Lo que cambia a propósito para mantenerlo pequeño:

AngularAngeLite Lite
Decoradores + TypeScript + compiladorcomponent(Clase, meta) en JS plano (también hay Component(meta) como decorador si tu toolchain los soporta)
Zone.js / detección de cambiosSeñales: solo se actualiza lo que depende de ellas. Mutar una propiedad normal no repinta; usa signal.
@Input() / @Output()input() / output()
[(ngModel)]="prop"[(ngModel)]="signal" (la señal debe ser escribible)
Asignaciones en plantillas ((click)="x = 1")No: (click)="x.set(1)"
Formularios reactivos, HTTP, animaciones, SSRFuera de alcance (usa fetch y señales)

Seguridad: la interpolación escribe siempre texto. Si enlazas [innerHTML] es tu responsabilidad sanear el contenido.
