Componentes

21 componentes listos para usar, construidos con AngeLite Lite. JS + CSS pesan ~5 KB gzip en total. Cada demo de esta página es código real que se ejecuta aquí mismo.

<script src="angelite-lite.min.js"></script>
<script src="angelite-ui.min.js"></script>
<script>
  const { component, mount, signal } = AngeLite;
  const ui = AngeLiteUI;

  class App { n = signal(0); }
  component(App, {
    imports: [ui.Button],              // o: imports: ui.all
    template: `<ui-button variant="primary" (click)="n.set(n() + 1)">Clicks: {{ n() }}</ui-button>`
  });
  mount(App, document.body);
</script>

En los ejemplos están disponibles signal, computed, component, mount, input, output, inject (de AngeLite) y ui (AngeLiteUI). Los componentes son controlados: el valor vive en tu señal y el componente avisa con un output. Los colores salen de variables CSS --ui-* y respetan el modo oscuro. Las expresiones de plantilla no admiten funciones flecha: usa métodos de la clase.
